## 当前真实能力
### 已可运行
- 前端收集页可输入内容并提交
- 保存后反馈区：继续记录(主) / 补思考(次) / 加入专题(弱入口)
- 可通过下拉搜索选择或创建专题
- 保存后可立即补一句思考（insight_text 写入数据库）
- 保存后可加入专题（topicId 绑定）
- 后端 `PATCH /api/entries/:id/insight` 补思考
- 后端 `PATCH /api/entries/:id/topic` 更换专题
- 后端 `GET /api/topics` 专题列表 + `GET /api/topics/search` 模糊搜索
- 后端 `GET /api/entries/pending` 待处理流（自动推导建议动作）
- 后端 `POST /api/entries/:id/skip` 跳过（24小时后再出现）
- 前端待处理页：统一处理流、补思考、加专题、跳过
- 收集页底部待处理数量提示与跳转
- 全局顶部导航栏（收集/查找/待处理/专题）
- 后端 `GET /api/entries/search` 全文搜索（支持专题、思考筛选）
- 后端 `POST /api/entries/:id/reuse` 记录复用行为
- 前端查找页：关键词搜索 + 筛选 + 复制原文/复制原文+思考
- 后端 `GET /api/topics/:id` 专题详情（含素材计数）
- 后端 `GET /api/topics/:id/entries` 专题内素材列表
- 前端专题列表页 + 专题详情页
- 后端 `GET /api/entries/:id` 素材详情
- 前端素材详情页（编辑思考/更换专题/复制）
