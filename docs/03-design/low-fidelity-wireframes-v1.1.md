# 低保真草图（V1.1 约束下）

## 1. 收集页
- 目标：快速录入 + 对刚保存条目做极轻处理
- 结构：输入框 / 保存 / 刚刚记录 / 去待处理入口

## 2. 待处理页
- 目标：15 秒内完成的轻动作
- 结构：待补一句思考 / 待加入专题 两类条目

## 3. 查找页
- 目标：找回并直接取用
- 结构：搜索框 / 过滤器 / 结果列表 / 相关专题
- 动作：复制原文、复制原文+思考、详情

## 4. 专题页
- 目标：围绕持续问题形成稳定上下文
- 结构：专题说明 / 本专题搜索 / 相关素材列表

## 5. 详情页
- 目标：把单条内容搞清楚并方便带走
- 结构：原文 / 来源 / 一句话思考 / 所属专题 / 复制动作

## 低保真总原则
- 不做输出清单
- 不做首页工作台
- 不做时间线独立页
- 不做回顾独立页
- 不做专题工作台
