# 页面职责重构表 V1.1（实施前定稿）

## 一级入口
- 收集
- 查找

## 一级候选 / 当前二级
- 专题

## 二级
- 待处理
- 详情

## 嵌入机制
- 回顾提醒
- 时间筛选
- 复制原文
- 复制原文+思考

## 关键约束
1. 首版“用”= 可直接取用，不做输出清单/输出篮/导出系统。
2. 待处理只承载 15 秒内可完成的动作。
3. 专题是“持续问题的稳定上下文”，不是分类目录或工作台。
4. 收集页禁止工作台化。
5. 查找页禁止吞掉专题经营、深整理、输出系统。

## 页面结论
### 收集
- 任务：快速录入
- 允许：保存、对刚保存单条补一句思考/加专题
- 禁止：大列表、重统计、输出动作

### 待处理
- 任务：轻处理最近内容
- 允许：补一句思考、加入一个专题、跳过、进详情
- 禁止：长文本编辑、复杂分类、输出整理

### 查找
- 任务：找回并直接取用
- 允许：搜索、过滤、复制原文、复制原文+思考、进详情、进专题
- 禁止：深编辑、输出清单、专题管理

### 专题
- 任务：围绕持续问题聚合素材
- 允许：看相关素材、看每条素材思考、搜索本专题、进详情
- 禁止：工作台化、进度面板、输出中心、文件夹树

### 详情
- 任务：单条完善
- 允许：看完整原文、看来源、改一句思考、更换专题、复制
- 禁止：推荐流、关系图、AI面板、历史复用中心
