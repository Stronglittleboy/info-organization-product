# 后端框架可用性验证记录 V1

## 验证目标
验证 Spring Boot 3 + MyBatis-Plus 项目骨架是否具备最小可用性。

## 验证结果
### 第三方服务连通性
- 域名：`wangliang.dns.army`
- PostgreSQL 端口：`55432`
- DNS：解析成功
- TCP：连通成功
- 数据库：表已初始化成功

### Maven 构建验证
- 原问题：Maven Central TLS 握手失败
- 修复：新增 `settings.xml`，切换阿里云 Maven 镜像
- 结果：**构建成功**

### Spring Boot 最小启动验证
- 启动方式：Docker JRE 运行构建后的 JAR
- 第一次失败：宿主端口 `18080` 被占用
- 修复：切换到 `18081`
- 结果：**应用成功运行**
- 本地探测：`http://127.0.0.1:18081/api` 返回 `401`

## 结论
后端框架最小可用性验证通过：
1. 代码骨架可构建
2. 应用可启动
3. 数据库可连接
4. Spring Security 默认拦截生效（401 为预期）
