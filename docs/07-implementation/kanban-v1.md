# 7. 任务状态更新规则

## 状态流转
```
Backlog → Todo → In Progress → In Review → Done
```

## 更新时机
- 开始任务：Backlog/Todo → In Progress
- 完成开发：In Progress → In Review
- 通过评审：In Review → Done
- 发现问题：In Review → In Progress

---

# 8. 验收标准模板

每个任务必须满足：
1. 代码符合规范
2. 单元测试通过（后端）
3. 功能测试通过
4. 代码已提交
5. 文档已更新
