# 2. 全局交互原则

## 2.1 全局导航
一级入口：
- 收集
- 查找

二级/上下文入口：
- 待处理
- 专题
- 详情

## 2.2 全局原则
1. 任何页面都不能重新工作台化。
2. 首版“用”只等于：复制原文 / 复制原文+思考。
3. 待处理页只允许 15 秒动作。
4. 专题不做工作台，只做持续问题上下文。
5. 详情页不做超级中心页。

## 2.3 全局组件优先级
- 一级主按钮：当前页面核心动作
- 二级按钮：跳转/轻处理
- 三级入口：更多信息，不默认展开

# 3. 页面一：收集页（中保真）

## 3.1 页面目标
让用户在最短路径内完成录入，并在保存后感知“可以稍后补结构”。

## 3.2 页面结构

```text
顶部栏
├─ 页面标题：收集
├─ 一级切换：查找
└─ 右侧入口：待处理

主输入区
├─ 多行输入框
├─ 来源辅助入口（粘贴/链接/截图）
└─ 保存按钮（主按钮）

保存后反馈区（仅保存成功时出现）
├─ 已保存提示
├─ 补一句思考
├─ 加入专题
└─ 完成

刚刚记录区
├─ 最近 3~5 条
└─ 每条支持：补一句思考 / 加入专题 / 详情

页底轻提醒
└─ 还有 N 条最近内容可去待处理继续处理
```

## 3.3 关键组件行为

### 输入框
- 默认焦点进入页面后可直接输入
- 占位文案：`记下一条以后可能用得上的内容...`
- 支持多行
- 不要求标题字段

### 保存按钮
- 为空不可点击
- 保存后不跳页
- 保存后进入“已保存反馈区”状态

### 已保存反馈区
- 生命周期：本次保存后出现，用户完成/离开页面后消失
- 作用：只服务刚保存条目，不作用于整个列表

## 3.4 页面状态
- 初始空状态
- 输入中状态
- 保存成功状态
- 刚刚记录非空状态

## 3.5 禁止事项
- 禁止出现统计大盘
- 禁止出现全量历史记录
- 禁止出现复制/输出动作

# 4. 页面二：待处理页（中保真）

## 4.1 页面目标
用最小动作让最近内容获得最基础结构：一句思考 / 一个专题归属。

## 4.2 页面结构

```text
顶部栏
├─ 返回：收集
└─ 页面标题：待处理

提醒条
└─ 最近有 N 条内容只有原文，没有你的理解

标签切换
├─ 待补一句思考
└─ 待加入专题

内容列表
└─ 条目卡片（单列）
   ├─ 内容摘要
   ├─ 来源与时间
   ├─ 一句话思考输入区 或 现有思考展示
   ├─ 专题选择器
   └─ 动作：保存 / 跳过 / 详情
```

## 4.3 条目卡交互

### 情况 A：无思考
- 默认展开一句思考输入框
- 主动作：保存
- 次动作：跳过 / 详情

### 情况 B：有思考但无专题
- 默认展示已有思考
- 主动作：加入专题并保存
- 次动作：详情

### 情况 C：有思考且已入专题
- 不再出现在待处理主列表

## 4.4 页面状态
- 列表为空：提示“当前没有待处理内容”
- 有列表：按最近优先排序
- 跳过后：该条后移，不立刻消失全部痕迹

## 4.5 硬约束
- 一屏只允许极少字段
- 任何条目必须能在 15 秒内完成
- 不得出现大段正文编辑

# 5. 页面三：查找页（中保真）

## 5.1 页面目标
让用户把过去内容找回来，并直接拿走使用。

## 5.2 页面结构

```text
顶部栏
├─ 页面标题：查找
├─ 一级切换：收集
└─ 可选入口：相关专题

搜索区
├─ 搜索框
└─ 筛选条（时间 / 是否有思考 / 专题）

结果区
└─ 结果卡片列表
   ├─ 内容片段
   ├─ 一句话思考
   ├─ 专题
   ├─ 来源与时间
   └─ 动作：复制原文 / 复制原文+思考 / 详情

页底/侧下推荐
└─ 相关专题
```

## 5.3 搜索交互
- 支持内容全文、思考全文、专题名
- 搜索词为空时，不默认展示全量结果，可展示最近检索或空引导
- 默认开启：仅看有思考

## 5.4 结果卡规则

### 信息层级
1. 内容片段
2. 一句话思考
3. 专题
4. 来源与时间
5. 操作按钮

### 动作优先级
- 主按钮：复制原文+思考
- 次按钮：复制原文
- 三级入口：详情

## 5.5 页面状态
- 初始状态：空搜索引导
- 有结果状态
- 无结果状态

## 5.6 禁止事项
- 禁止在结果页直接深编辑
- 禁止加入输出清单
- 禁止拖拽编排
- 禁止专题经营功能

---

# 6. 页面四：专题页（中保真）

## 6.1 页面目标
让用户围绕一个持续问题集中查看已沉淀素材。

## 6.2 页面定位
当前为：
- 二级页
- 一级候选，不在当前交互稿中提升为一级

## 6.3 页面结构

```text
顶部栏
├─ 返回：查找 或 详情
└─ 页面标题：专题名称

专题说明区
└─ 一句话说明该专题聚焦什么问题

专题内搜索区
└─ 搜索本专题内容

专题列表区
└─ 条目卡片
   ├─ 内容摘要
   ├─ 一句话思考
   ├─ 来源与时间
   └─ 动作：详情
```

## 6.4 交互原则
- 专题是“上下文视图”，不是“运营视图”
- 不在这里做批量管理
- 不在这里做输出

## 6.5 页面状态
- 专题为空状态
- 专题有内容状态
- 专题内搜索命中/未命中状态

## 6.6 禁止事项
- 禁止进度面板
- 禁止观点工作台
- 禁止输出中心
- 禁止文件夹树

---

# 7. 页面五：详情页（中保真）

## 7.1 页面目标
把一条素材讲清楚，并允许带走。

## 7.2 页面结构

```text
顶部栏
├─ 返回来源页
└─ 页面标题：详情

原文区
└─ 完整原文，可折叠/展开

来源区
├─ 来源类型
├─ 来源名称/链接
└─ 记录时间

思考区
├─ 标题：我的一句思考
├─ 文本内容或输入框
└─ 编辑入口

专题区
├─ 当前所属专题
└─ 更换专题

动作区
├─ 复制原文
└─ 复制原文+思考
```

## 7.3 交互规则
- 若无思考，详情页允许补一句思考
- 若无专题，详情页允许加入专题
- 复制动作始终位于页面下部稳定位置

## 7.4 页面状态
- 有思考 / 无思考
- 有专题 / 无专题
- 来源完整 / 来源缺省

## 7.5 禁止事项
- 禁止推荐流
- 禁止历史复用记录
- 禁止关系图
- 禁止 AI 面板

# 8. 页面跳转关系

```text
收集
├─ 保存后停留当前页
├─ 去待处理
└─ 进详情

待处理
├─ 保存后留在当前列表
├─ 跳过后进入下一条
└─ 进详情

查找
├─ 结果 -> 详情
└─ 结果 -> 专题

专题
└─ 条目 -> 详情

详情
├─ 返回来源页
└─ 可更换专题
```

# 9. 中保真交互重点

## 9.1 收集页的重点
- 录入优先级最高
- 任何“后处理”都只能围绕刚保存单条展开

## 9.2 待处理页的重点
- 一条一条快速过带
- 不是后台治理页

## 9.3 查找页的重点
- 搜到即能拿走
- 不承担深加工

## 9.4 专题页的重点
- 提供稳定上下文
- 不承担管理和输出

## 9.5 详情页的重点
- 把一条内容搞明白
- 支持复制带走

# 10. 进入下一阶段前的检查项

5. UI 不会把收集页重新画成工作台
